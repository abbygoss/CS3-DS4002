# CS3-DS4002
This repository contains the study, deliverable, data, and reference materials necessary to complete the Case Study.
## Important Information
The two attached PDFs include both the hook for the case study as well as a rubric to follow in order to meet all requirements successfully.
## Data
The necessary data is located in the "DATA" folder and includes a data dictionary describing the RealWaste dataset. The full image dataset must be downloaded directly from the UCI Machine Learning Repository due to its size.
## Reference Materials
The "Reference Materials" folder contains helpful resources related to the context of the issue, an accessible introduction to convolutional neural networks and image classification in Python, and a technical article on applying deep learning to waste sorting tasks to get a better idea of the modeling approach, contextually.
